Notes Project — клиент-серверное приложение для заметок

Проект представляет собой клиент-серверное приложение для хранения заметок.
Сервер написан на языке Go и запускается в Docker-контейнере.
Клиент — консольное приложение.
В качестве базы данных используется PostgreSQL.
-----------------------------------------------------------------------------------------
Возможности

* создание заметок
* просмотр списка заметок
* просмотр заметки по её id
* удаление заметок
* хранение данных в базе PostgreSQL
* работа по TCP-соединению
* запуск сервера в Docker

Запуск сервера:

Перейдите в папку `server` и выполните команду:
bash
docker compose up --build

После запуска сервер будет доступен по адресу:
localhost:9000


Запуск клиента:

Запустите скомпилированный файл:
client.exe


-----------------------------------------------------------------------------------------

Меню клиента:

После запуска в терминале отображается следующее меню:
1. Создать заметку
2. Посмотреть список заметок
3. Открыть заметку по ID
4. Удалить заметку
0. Выход

База данных:

При первом запуске Docker Compose база данных создаётся автоматически.

Файл `init.sql` выполняется контейнером PostgreSQL и:

- создаёт базу данных `notes` (если не существует)
- подключается к ней
- создаёт таблицу `notes`

Используемый SQL-скрипт:

sql
DO
$do$
BEGIN
   IF NOT EXISTS (
      SELECT FROM pg_database WHERE datname = 'notes'
   ) THEN
      CREATE DATABASE notes;
   END IF;
END
$do$;

\c notes

CREATE TABLE IF NOT EXISTS notes (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT,
    created_at TIMESTAMP DEFAULT NOW()
);

Технические команды (для отладки):

Используется простой текстовый TCP-протокол:


CREATE|title|content
LIST
GET|id
DELETE|id


Пример:


CREATE|Test|Hello world
GET|1
